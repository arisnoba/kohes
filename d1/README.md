## 테이블

| 테이블                | 용도                                                                                |
| --------------------- | ----------------------------------------------------------------------------------- |
| `survey_responses`    | 응답 ID, 중복 제출 키, 요청 해시, 연도/스키마 버전, 제출 시각, 응답 JSON, 경품 상태 |
| `survey_response_pii` | 응답과 1:1로 연결되는 개인정보 JSON, 보유기간 종료 시각                             |
| `export_passwords`    | 서버에서 생성한 내보내기 비밀번호 해시. 초기 비밀번호는 입력하지 않음               |
| `export_logs`         | 관리자 식별자, 내보내기 범위/형식/건수/시각. 응답 원문은 저장하지 않음              |

SQLite에서는 JSON을 TEXT로 저장하고 `json_valid` 제약으로 유효성을 검사합니다. 개인정보 비동의 응답은 개인정보 행을 만들지 않고 경품 상태를 `추첨 대상 아님`으로 저장합니다. 보유기간 종료 시각을 저장한다고 자동 삭제가 실행되지는 않습니다.

`submission_key`는 재시도 시 같은 결과를 반환하기 위한 UNIQUE 키입니다. 같은 키로 내용이 달라지면 `payload_hash`를 비교해 거절해야 합니다. 응답과 개인정보 저장은 D1에서 검증한 원자적 실행 방식으로 처리해야 하며, 현재 SQL 제약만으로 API의 재시도/원자성이 구현된 것은 아닙니다.

## 로컬 사용

```bash
pnpm db:init:local
pnpm exec vitest run tests/unit/d1-schema.spec.ts
```

`db:init:local`은 시스템의 `sqlite3` 실행 파일을 사용하며 `.local/d1/kohes-survey-2026.sqlite`에만 DB를 생성합니다. 기존 파일이 있으면 덮어쓰지 않고 종료합니다. Cloudflare 자격 증명이나 Supabase 환경변수를 읽지 않습니다. 생성한 DB는 Git에서 제외합니다.

이 단계에서는 원격 데이터 입력, 기존 DB 삭제, 운영 환경변수 변경이나 배포를 실행하지 않았습니다.

## 2026-10-07 앱 연결 구현

설문 제출, 관리자 응답 페이지/통계, 암호화 내보내기, 내보내기 비밀번호/이력 저장을 D1 REST 경로로 교체했습니다. 관리자 로그인은 서버 환경변수의 이메일/비밀번호 해시를 확인하고 8시간 유효한 서명된 HttpOnly 쿠키를 사용합니다. 서버 페이지의 데이터 조회와 API 모두 인증을 확인합니다. Supabase 파일은 과거 구성 참고용으로 남아 있으나 현재 화면에서는 사용하지 않습니다.

`.env.example`을 참고해 `.env.local`에 서버 변수를 설정합니다. API 토큰에는 지정 계정의 D1 Edit 권한이 필요합니다. 토큰과 관리자 비밀번호를 채팅이나 Git에 올리지 않습니다.

비밀번호 해시는 로컬 터미널에서 아래 명령으로 만듭니다. 입력 중 문자가 표시되지 않습니다. 출력된 해시를 `ADMIN_PASSWORD_HASH`에 저장합니다.

```bash
read -s 'kohes_password?관리자 비밀번호: '
printf '%s' "$kohes_password" | node scripts/admin-password-hash.mjs
unset kohes_password
node -e "console.log(require('node:crypto').randomBytes(32).toString('hex'))"
```

마지막 명령의 출력은 `ADMIN_SESSION_SECRET`에 설정합니다. 해시와 세션 비밀값은 로그에 남기지 않습니다. `ADMIN_EMAIL`에는 로그인할 관리자의 이메일을 설정합니다. 내보내기 비밀번호는 관리자 비밀번호 관리 화면에서 최초 설정하며 기본값은 없습니다.

로컬 개발은 `D1_LOCAL=1 pnpm dev`로 실행합니다. `.local/d1/kohes-survey-2026.sqlite`만 사용하며 production에서는 로컬 모드를 거절합니다. 서버리스 환경에서 로그인 요청 제한은 인스턴스 간 공유되지 않으므로 운영 오픈 전 플랫폼에서 `/api/admin/auth` 요청 제한을 설정해야 합니다.

실제 D1 REST 요청/응답 저장, 운영 환경변수 설정과 배포는 아직 검증하거나 실행하지 않았습니다. 원격 스키마 생성 확인과 앱 연결 구현 완료는 구분합니다.

검증 결과: 단위 테스트 44개, TypeScript 검사, ESLint, production 빌드 통과. 별도 로컬 SQLite 확인에서 응답/개인정보 저장, 동일 요청 재시도의 같은 ID 반환, 같은 키의 변경된 요청 거절을 확인했고 테스트 행은 로컬에서 제거했습니다. Cloudflare API 요청은 단위 테스트에서 모의 응답으로 검증했으며 원격 DB에 테스트 데이터를 입력하지 않았습니다.
